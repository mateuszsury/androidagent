# Code of conduct

We want a respectful, useful community for people building and using androidagent.

- Be considerate of different experience levels, backgrounds and accessibility needs.
- Discuss the code, evidence and behavior; avoid insults, harassment, threats, discrimination and sexualized content.
- Respect privacy. Do not publish another person's credentials, personal messages or identifying information without permission.
- Keep issues and pull requests focused. Explain disagreements with concrete examples and accept corrections when evidence changes.
- Follow the project's licenses and security-reporting process.

Maintainers may edit/remove harmful content, close abusive discussions, restrict participation or block repeat offenders. These rules apply to project issues, pull requests and other project community spaces.

For abuse, use GitHub's report-abuse tools and contact a maintainer through an available private channel. Do not publish private incident details in an issue. Technical vulnerabilities follow [Security](SECURITY.md). Reports will be handled with discretion, subject to the platform's reporting tools.
