# Support

Start with the [README](README.md), [documentation index](docs/README.md) and [known validation limits](docs/TESTING.md).

| Problem | Guide |
| --- | --- |
| Install, signing or build | [Building](docs/BUILDING.md) |
| Model setup/account login | [Agent setup](docs/CLAUDE.md) and [terminal provenance](docs/TERMINAL-SOURCES.md) |
| Phone permission/background behavior | [Permissions](docs/PERMISSIONS.md) |
| VM startup, preview, export or cleanup | [Docker](docs/DOCKER.md) and [WebView](docs/WEBVIEW.md) |
| OTG, UART, ESP, second Android or storage | [USB](docs/USB.md) |

Use a [bug report](https://github.com/mateuszsury/androidagent/issues/new?template=bug_report.yml), [feature request](https://github.com/mateuszsury/androidagent/issues/new?template=feature_request.yml) or [usage question](https://github.com/mateuszsury/androidagent/issues/new?template=question.md). Include app version, device/Android/ABI, steps and sanitized error output. For Docker startup, save the bounded diagnostics through the UI or MCP before resetting the VM.

Do not post keys, tokens, login codes, account archives or unrelated personal files. Provider account/subscription/model availability is managed by OpenAI or Anthropic; androidagent does not supply an account or override their access controls. Physical accessory compatibility depends on the device, cable and power as well as software.

Contributors maintain this community project without a guaranteed support schedule. Vulnerabilities should use the [private security process](SECURITY.md), not public issues.
