# Testy androidagent 0.1.0

Status roboczy: kompilacja i 8 testów kontraktu strumienia Codexa przeszły. Testy na emulatorze są w toku; wyniki zostaną uzupełnione przed przekazaniem wydania.

Nie należy traktować testów protokołu jako potwierdzenia rozmowy z prawdziwym modelem. Taki test wymaga zalogowania właściciela konta Codex. Testy aplikacji używają rzeczywistych API Androida, powłoki, serwera MCP oraz Accessibility. Kod testowy znajduje się w osobnym APK i nie jest częścią aplikacji.
